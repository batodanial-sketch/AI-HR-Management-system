## 6. Central proxy audit (`lib/ai-proxy.ts`)

`proxyToBridge` resolves the canonical RBAC context itself and **fails closed** (401/403 before any upstream I/O); the tenant forwarded as `X-Organization-Id` is always the canonical session org (never a header/body claim); pilot controls (kill switch, allowlist, budget ceilings) gate each call; tier-based rate limiting (`Trial 30 / Pro 120 / Enterprise 600 req/min`, org-scoped keys) and AI-usage metering + telemetry apply; upstream hostname is never echoed to clients; bridge secret is attached from env. Findings: no auth hole — every thin route inherits all of the above. **Gap fixed:** the upstream `fetch` had no wall-clock bound (see §9). New exported constants `BRIDGE_PROXY_TIMEOUT_MS = 150_000` (proxied round-trip incl. streaming/engine endpoints) and `BRIDGE_LLM_TIMEOUT_MS = 120_000` (direct single-LLM round-trips) sit 30–60 s above the bridge's own internal 90 s provider cap.

## 7. Middleware gate audit (`middleware.ts`)

The gate exempts exactly three classes: static/marketing surfaces; public API prefixes (`/api/license`, `/api/auth`, `/api/account`, `/api/health`) that self-protect; and integration prefixes (`/api/webhooks/`, `/api/desktop/`, `/api/scim/`) that authenticate via their own secrets. Everything else requires a live Supabase session + license/trial cookie, and module-CRUD paths get org-keyed edge rate limiting. **Finding (genuine gap):** four operator/external endpoints authenticate with their own route-level credentials but were **not** exempt, so a cookie-less legitimate caller (Prometheus, cron daemon, workflow engine) was redirected to `/login` before the handler's token check could ever run: `/api/metrics` (`METRICS_TOKEN`), `/api/system/cron` + `/api/cron/daily-workflows` (`CRON_SECRET` via `x-cron-secret`), `/api/workflows/webhooks` (`WORKFLOW_WEBHOOK_SECRET` HMAC). **Fix:** §10. After the fix, direct calls return the handler's own fail-closed responses (verified live: `/api/system/cron` → JSON `CRON_SECRET is not configured.`, `/api/cron/daily-workflows` → 503, `/api/workflows/webhooks` → 401, `/api/metrics` → 404 when `METRICS_BACKEND` unset, 401 on bad token).
